# Intellectual Property, Privacy and Preservation Notes

Old Web Rescue Lab is an independent research and prototyping project.

## Independent prototypes

Pilot 001 reproduces only the generic interaction pattern of revealing two cards and retaining matching pairs. It does not include Space Jam characters, film imagery, music, copied source code or Warner Bros. branding. It is not affiliated with or endorsed by Warner Bros.

## Archived material

A page being retrievable from a public web archive does not mean it is public domain or cleared for republication. Archived websites can contain copyrighted text and images, trademarks, personal details, third-party links and content whose original context has been lost.

This repository favors metadata, source links, capture timestamps and limited structural observations. Do not add bulk mirrored content, images, personal data or third-party logos unless the rights and necessity are clear.

## Safe inspection

- Treat HTML, scripts, links, downloads and embedded content as untrusted.
- The local HTML auditor parses saved source and does not run scripts or make network calls.
- Do not automatically visit outbound destinations extracted from archive pages.
- Do not bypass access controls or retrieve restricted material.
- Respect archive/API terms, robots policies where applicable, rate limits and preservation provider guidance.

## Rights status

This repository currently does not grant a blanket license to third-party archived material. Each contributor must retain attribution and rights/provenance information for added assets and code. A repository-wide open-source license should be added only after the owner explicitly selects one and any included content is reviewed for licensing compatibility.
